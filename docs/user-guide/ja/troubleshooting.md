# トラブルシューティング

> English version: [English](../troubleshooting.md)

## Canvas Extension を使用できない

- リポジトリに `.github/extensions/markdstage/` が含まれていることを確認するか、
  信頼できるリリースタグから Extension をユーザースコープへインストールします。
- インストール後にプロジェクトを開き直します。
- Canvas を直接開くワークフローでは Canvas ID `MarkdStage` を使用します。

## Desktop のプレビューを初期化できない

Microsoft Edge WebView2 Runtime をインストールまたは修復し、MarkdStage Desktop を再起動します。
ユーザープロファイルがローカルアプリケーションデータフォルダーへ書き込めることも確認してください。

## Canvas の読み込み画面に Markdown ファイルが表示されない

- ファイル名が `.md` または `.markdown` で終わることを確認します。
- 現在のワークスペース内にファイルがあることを確認します。
- Git リポジトリでは、リポジトリルートがワークスペースルートです。

ワークスペース外のパスは選択できません。

## 意図しない位置でスライドが分割される

- `---` の前に空行を入れます。
- 区切りは単独の行に記述します。
- フェンス付きコードブロックを正しく閉じます。
- テキスト直下の `---` は Setext 見出しとして解釈される場合があります。

## 保存したファイルが更新されない

- Canvas では **Refresh automatically on save** が有効であることを確認します。
- Desktop では同じファイルが選択されたままであることを確認します。
- 空、読み取り不能、無効な Markdown を修正します。MarkdStage は最後の有効なデッキを維持し、
  次の有効な保存で復旧します。

## 画像が表示されない

- Markdown では `/assets/file.png` を使用します。
- Architecture DSL では `assets/file.png` を使用します。
- Markdown と同じ場所、またはワークスペースルートの `assets/` にファイルを配置します。
- `..` を使用してワークスペース外へ移動しないでください。
- 大文字と小文字、および拡張子を確認します。

## カスタムテーマを読み込めない

- `theme: custom` と相対パスの `theme-file` を指定します。
- Markdown と同じ場所、またはワークスペースルートにテーマを配置します。
- CSS カスタムプロパティの宣言だけを使用します。
- セレクター、`@import`、`url()`、JavaScript、外部パスを削除します。
- `theme.json` を検証します。無効なメタデータファイルは無視されず、エラーとして報告されます。

## PDF でスライドがクリップされる

Canvas で **16:9** を選択し、警告から対象ページを確認します。コンテンツを短くするか、
スライドを分割してください。`layout: center` は配置を変更するだけで、利用可能な領域は増えないため、
クリッピングの解決にはなりません。

## Mermaid または Architecture でエラーが表示される

- フェンスの名前と閉じフェンスを確認します。
- Mermaid 構文を検証します。
- Architecture JSON、要素 ID の一意性、参照、位置、対応する値を検証します。
- 図のエラーを修正している間も、スライドの他のコンテンツは表示されます。

## Architecture の変更を保存できない

- Advanced editing には **📂** で読み込んだ Markdown が必要です。
- ソースに `architecture` ブロックが必要です。
- ソースが外部で変更された場合は、新しいファイルを上書きせずに再読み込みします。
- レイアウト管理下の子要素を手動で移動する前に、親グループのレイアウトから解除します。

## オーディエンスウィンドウを全画面表示にできない

オーディエンスウィンドウへフォーカスを移し、`F11` を押します。`Esc` でウィンドウ表示へ戻ります。
他のアプリケーションがキーを取得する場合は、オペレーティングシステムのウィンドウ操作を使用してください。
