# プレゼンテーションとエクスポート

> English version: [English](../presenting-and-export.md)

Canvas と Desktop は同じレンダラーを使用するため、オーディエンス向けの出力は一貫しています。
プレゼンテーションの準備機能とエクスポート機能はサーフェスごとに異なります。

## プレゼンテーション機能を比較する

| 機能 | Canvas Extension | Desktop |
| --- | --- | --- |
| 現在のスライド | 対応 | 対応 |
| 次のスライドのプレビュー | 発表者ビュー | メインウィンドウ |
| スピーカーノート | 発表者ビュー | メインウィンドウ |
| スライド一覧 | 対応 | 対応 |
| 外部／オーディエンスウィンドウ | 対応 | 対応 |
| 同期ナビゲーション | 対応 | 対応 |
| オーディエンスの全画面表示 | `F11` | `F11` |
| 16:9 クリッピングプレビュー | 対応 | 非対応 |
| PDF エクスポート | 対応 | 非対応 |
| Surface Pen | Windows で対応 | オーディエンスウィンドウ表示中に対応 |

## 発表者ビューを準備する

Canvas の発表者ビュー、または Desktop のメインウィンドウを開き、次の点を確認します。

- 現在のスライドが正しい
- 次のスライドのプレビューが役立つ
- スピーカーノートに発表者向けの内容だけが含まれている
- スライド一覧のタイトルが明確である

![プレゼンテーション用に準備した Canvas の発表者ビュー](../images/canvas-presenter-view.png)

## オーディエンスウィンドウを開く

- **Canvas:** **⛶**、または発表者ビューの **Start presentation** を選択します。
- **Desktop:** **Start presentation** を選択します。

新しいウィンドウをオーディエンス用ディスプレイへ移動します。`F11` で全画面表示にし、
`Esc` で解除します。発表者側とオーディエンス側の操作は同期されます。

## 固定 16:9 出力を確認する

Canvas Extension で **16:9** を選択します。PDF 出力と同じ 1280x720 のタイポグラフィ、
間隔、コンテンツ制限を使用して、スライドをレターボックス表示します。

コンテンツが固定ページを超えると、MarkdStage がクリッピング警告を表示します。

![現在のスライドが縦方向にクリップされることを示す 16:9 プレビュー警告](../images/canvas-layout-warning.png)

コンテンツを短くする、スライドを分割する、適切なレイアウトを使う、明示的に拡大した
コンテンツサイズを小さくする、のいずれかで警告を解消します。

Copilot にデッキの PDF レイアウトを検査させ、修正が必要なページを特定することもできます。

## PDF をエクスポートする

1. デッキを開いた後にソースが変更された場合は、再読み込みします。
2. **16:9** を選択し、クリッピング警告を解消します。
3. プリンターアイコンを選択します。
4. ワークスペースに生成された PDF を開き、すべてのページを確認します。

Markdown からデッキを読み込んだ場合、Canvas Extension はソースファイル名から PDF 名を生成します。
エクスポートファイルには、バックカバーを含む各スライドが1ページずつ 16:9 で出力され、
背景、画像、シンタックスハイライト付きコード、Mermaid、Architecture 図も含まれます。

スピーカーノートと Architecture 編集コントロールは出力されません。
