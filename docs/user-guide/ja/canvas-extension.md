# Canvas Extension

> English version: [English](../canvas-extension.md)

MarkdStage Canvas Extension は、GitHub Copilot 内で Markdown デッキ全体を開きます。
Markdown の修正を Copilot に依頼したり、ファイルを直接読み込んだり、Architecture 図を編集したり、
固定出力レイアウトを検証して PDF をエクスポートしたりできる、オーサリング向けのサーフェスです。

## Extension をインストールする

このリポジトリをプロジェクトとして開くと、`.github/extensions/markdstage/` の Extension が
プロジェクトスコープで読み込まれます。

別のリポジトリへユーザースコープでインストールする場合は、信頼できるリリースタグを選び、
Copilot に次のように依頼します。

> 次の GitHub リポジトリフォルダーから MarkdStage をユーザースコープへインストールしてください。
>
> `https://github.com/runceel/markdstage/tree/<release-tag>/.github/extensions/markdstage`

インストール前にローカル Extension のコードを確認してください。リリースタグまたはコミット SHA を使うと、
同じ内容を再現可能な形でインストールできます。

## デッキを開く

ワークスペースからの相対パスを指定して、Copilot にプレゼンテーションを依頼します。

```text
docs/user-guide/examples/quick-start.md を使ってこのデッキをプレゼンテーションしてください。
```

AI を使わずに読み込む場合は、**📂** を選択するか `I` を押します。

![自動更新を選択した Markdown 読み込み画面](../images/canvas-import.png)

読み込み画面にはワークスペース内の `.md` と `.markdown` ファイルが表示され、次の2つのモードを選べます。

| モード | 動作 |
| --- | --- |
| **Keep loaded snapshot** | 再読み込みまたはモード変更を行うまで、読み込んだデッキを変更しません |
| **Refresh automatically on save** | ソースファイルを監視し、有効な保存内容を再読み込みして、可能な限り現在のスライドを維持します |

監視中のファイルが空、読み取り不能、または無効になった場合、MarkdStage は最後の有効なデッキを維持します。
その後の有効な保存で自動的に復旧します。

## Copilot と作成・修正する

MarkdStage はスライド形式とテーマのガイダンス、Architecture DSL スキーマ、構造化された検証エラー、
固定 16:9 レイアウト診断、問題があるページの画像を Copilot へ提供できます。
これにより、同じセッション内で Copilot が Markdown を作成し、デッキを開き、結果を検査して、
ソースを修正する反復ワークフローを利用できます。

推奨ワークフローと依頼例は
[GitHub Copilot とスライドを作成する](ai-assisted-authoring.md)を参照してください。
プロンプトから PDF までの一連の演習は、
[GitHub Copilot ハンズオン](copilot-hands-on.md)を参照してください。

## コントロールバーを使う

![現在のスライド下部にある Canvas Extension のコントロールバー](../images/canvas-main.png)

| コントロール | 操作 |
| --- | --- |
| **◀ / ▶** | 前または次のスライドへ移動 |
| **ページカウンター** | 現在のページと総ページ数を表示 |
| **✎** | Architecture 配置編集を開始または終了 |
| **⛶** | 同期された外部オーディエンスウィンドウを開く |
| **Presenter アイコン** | 現在のスライド、次のスライド、ノートを表示する発表者ビューを開く |
| **16:9** | 固定 PDF レイアウトをプレビューし、クリッピング警告を表示 |
| **プリンター** | デッキ全体を 16:9 PDF としてエクスポート |
| **📂** | ワークスペースから Markdown ファイルを読み込む |
| **Refresh** | ソースに関連付けられたデッキのスナップショット／自動更新を切り替える |
| **☰** | スライド一覧を開く |

コントロールにポインターを合わせると、ツールチップとキーボードヒントが表示されます。

## スライドを移動する

- **◀** または **▶** を選択します。
- `Left` または `Right` を押します。
- スライドの空白部分を左クリックまたはタップすると次へ進みます。
- スライドの空白部分を右クリックすると前へ戻ります。
- `Home` または `End` で最初または最後のスライドへ移動します。
- **☰** を選択するか `O` を押してスライド一覧を開きます。

スライド内の操作可能なコンテンツ、リンク、画像、コントロールは通常どおり操作できます。

![ページを直接選択できるスライド一覧](../images/canvas-slide-list.png)

## 発表者ビューを使う

発表者ビューでは現在のスライドを大きく表示し、隣に次のスライドとスピーカーノートを配置します。
コントロールから移動、スライド一覧の表示、外部プレゼンテーションの開始と終了ができます。

![現在のスライド、次のスライド、スピーカーノートを表示した発表者ビュー](../images/canvas-presenter-view.png)

スピーカーノートは、現在のスライドにあるトップレベル HTML コメントから取得されます。
オーディエンス向けスライドやエクスポートした PDF には表示されません。

## オーディエンスウィンドウを開く

**⛶** を選択すると、移動とサイズ変更が可能な 1280x720 のオーディエンスウィンドウが開きます。
プレゼンテーション用ディスプレイへ移動し、`F11` で全画面表示にします。
Canvas、発表者ビュー、オーディエンスウィンドウは同じスライド位置に同期されます。

Canvas を閉じると、オーディエンスウィンドウも閉じます。

## 検証してエクスポートする

エクスポート前に **16:9** を使用します。PDF と同じ固定 1280x720 レイアウトで表示し、
コンテンツがクリップされる場合は警告します。手順の詳細は
[プレゼンテーションとエクスポート](presenting-and-export.md)を参照してください。

## Canvas 専用機能

次の機能は MarkdStage Desktop では使用できません。

- PDF エクスポートと PDF 相当のクリッピング確認
- 軽量な Architecture 配置編集
- Advanced Architecture Editor
- AI によるデッキの直接作成と修正
